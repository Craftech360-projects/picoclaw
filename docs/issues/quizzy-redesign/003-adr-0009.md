## What to build

`revealed` clearing a question is **not a bug**. It is a deliberate, documented
decision — [006-quizzy-prompt-cutover-e2e.md](../quiz-bank/006-quizzy-prompt-cutover-e2e.md)
line 15: *"Two wrong tries → reveal the answer warmly, emit `result=revealed`
(nothing blocks progression)."* The original design chose flow over mastery on purpose.

Reversing it is a design change, not a defect fix, so it needs an ADR before the code
lands. Write `docs/adr/0009-*.md` covering the three coupled decisions:

1. **Mastery over flow** — `revealed` stops clearing. State the cost being accepted:
   a mis-scored answer now costs a child a whole day, which is why the attempt log
   (004) ships first.
2. **One bank instead of eight age bands** — age is a poor ability proxy and eight
   banks is an unfundable authoring load; M1's Doors carry the range instead. This is
   the one decision here that is hard to reverse once content is merged (§13 Q1).
3. **Attempt logging** — per-attempt rows, so the effect of decision 1 is measurable
   from day one rather than from a parent complaint.

Also record the two decisions that fall out of these: Riddler keeps flow via a
per-bank flag (006), and the parent-app wire contract stays frozen (005).

**Numbering:** 0006 is taken (transcript expiry); this repo is at 0008. The next free
number is **0009**.

Fold in whatever 001 and 002 turn up — if the real prompt or the blast radius
contradicts a premise, the ADR records the corrected version, not the GDD's guess.
